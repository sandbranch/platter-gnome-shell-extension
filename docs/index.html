The album art of whatever is playing, back on your desktop.

A GNOME Shell extension that brings back CoverGloobus, a beloved little desktop widget from 2009–2012 that the world almost forgot. It sits behind your windows the way the original did — like an old-school desklet, not a floating app — follows whatever's playing, and shows up wearing a different outfit every time you feel like a change.

GNOME Shell only, for now — no KDE, Xfce, or standalone version.

Any MPRIS2 player

Spotify, Rhythmbox, Plexamp, whatever you actually use — Platter follows whichever one is playing.

56 themes

Mostly restored from the CoverGloobus and NowPlaying corpus of 2009–2012, plus a couple written from scratch — each with a preview in the picker.

Bring your own theme

Point Platter at a CoverGloobus or NowPlaying skin.xml theme, archive or folder, and it converts on the spot.

Installing

Requires GNOME Shell 48, 49 or 50. extensions.gnome.org submission is on the way — for now, install from a checkout:

git clone git@github.com:sandbranch/platter-gnome-shell-extension.git
cd platter-gnome-shell-extension
make install
  1. Log out and back in. GNOME Shell caches extension modules for the life of the session, so disabling and re-enabling keeps running the old code.
  2. Enable Platter in the Extensions app.
  3. Open its preferences to pick a theme, a placement, and a monitor.
Adding a theme of your own: Preferences → Theme → Add a theme → Folder… or Archive…, pointed at the theme exactly as you downloaded it.

56 themes, and counting

Hundreds more were made for CoverGloobus at its peak, scattered across DeviantArt, gnome-look and file hosts that no longer exist. These are the ones cleared to ship — full credits, licences and links to every author's original page are in docs/credits.md.
